# Assets

- **3D board, salon, and pieces** — original procedural meshes and materials in this repository. Not a commercial Staunton set.
- **Icon** — original SVG king/knight/board mark in the Shadowfetch black-and-gold palette.
- **Fonts** — Inter and Inter Display. See `assets/fonts/LICENSE-Inter.txt`.
- **Audio** — short procedural WAV tones generated in `AudioManager`. No sampled music beds.

No third-party chess-piece packs, no scraped commercial sets, no machine-specific paths in tracked source.
