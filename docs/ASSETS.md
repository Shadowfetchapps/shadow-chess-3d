# Assets

Every model, texture, sound, and icon in this repository is original and generated by scripts in `tools/assetgen/` (see its README for exact commands). No third-party chess sets, sampled audio, or scanned textures are used.

| Asset | Source | Regenerate |
|---|---|---|
| Pieces, board tile, frame, base (`assets/models/*.obj`) | Procedural Blender 5 pipeline: lathed profiles, booleans, and a distance-field sculpted knight | `blender -b --factory-startup --python tools/assetgen/build_models.py` |
| Board, room, and piece textures (`assets/textures/*`) | Procedural numpy generator: tileable albedo, normal (OpenGL +Y), and roughness sets | `python3 tools/assetgen/gen_textures.py` |
| Environment light (`assets/textures/env/salon.hdr`) | Procedural HDR panorama of the salon | same script |
| Sound effects and music (`assets/audio/*.ogg`) | Physical/modal synthesis and additive instruments in numpy, encoded with ffmpeg/libvorbis | `python3 tools/assetgen/gen_audio.py` |
| UI icons | Original 24 × 24 stroke SVGs in `scripts/ui/icon_library.gd`, rasterised at runtime | — |
| App icon | Original SVG (`icon.svg`, `assets/icons/`) | — |
| Fonts | Inter and Inter Display, SIL Open Font License 1.1 (`assets/fonts/LICENSE-Inter.txt`) | — |

The menu backdrop replays the Opera Game (Morphy vs Duke Karl of Brunswick and Count Isouard, Paris 1858), a public-domain game score. Puzzle positions and the opening book were composed for this project; the openings themselves are standard theory.
